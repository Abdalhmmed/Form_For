# Form Forge (مصمم النماذج)

منصة مكتبية مستقلة لتصميم النماذج والاستمارات بدقة متناهية، تعبئتها، وتصديرها كملفات PDF رسمية متجهة، دون الحاجة لأي خادم أو حفظ للبيانات.

---

## الميزات الرئيسية
- **الخصوصية والأمان:** لا توجد قاعدة بيانات أو تتبع؛ العمليات تتم 100% في ذاكرة المتصفح.
- **صيغة الهيكل الذكية (`.formdef.json`):** تصدير هيكل النموذج فقط واستيراده لاحقاً لإعادة بنائه في ثانية واحدة.
- **تصدير PDF عالي الدقة:** محرك طباعة متجهي يحافظ على وضوح الخط العربي دون أي تشويش.
- **دعم كامل للغات (i18n):** تبديل سلس للغات مع عكس اتجاه الواجهة (RTL/LTR) والخطوط تلقائياً.
- **تجاوب تام:** مصمم ليعمل بسلاسة على الهواتف الذكية (درج سفلي وأزرار عائمة)، الأجهزة اللوحية، وشاشات الحواسيب.
- **تراجع وتقدم (Undo/Redo):** دعم كامل لسجل التعديلات واختصارات لوحة المفاتيح `Ctrl+Z` و `Ctrl+Y`.

## التشغيل محلياً

